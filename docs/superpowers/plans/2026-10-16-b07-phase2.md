## The mathematics being tested

All of item 1 is under Phase 1's reading V, in the ϖ direction, with ε and the metric fixed, on the flat model (B = d, ε = 1, constant coefficients; Phase 1 H5 removes the dressing). Notation as Phase 1: pair(x, y) = Tr(x∧y)/2^{n/2}; C1, C2 as in Phase 1 H2, H3.

**H9 — the transpose.** For an algebraic X: Ω²(ad) → Ω^{n−1}(ad) define the wedge transpose Xᵗ: Ω¹ → Ω^{n−2} by pair(t, Xβ) = pair(Xᵗt, β). Then ∫Tr(T∧Xdα) = ∫Tr(α∧d(XᵗT)), so **L† = d∘Xᵗ**. Graded cyclicity gives pair(a, e^k∧Xᵗt) = −pair(t, X(e^k∧a)), so the symbol of L† − L pairs to −C1: Phase 1's C1 is recovered exactly (executable).

**H10 — is L† algebraic on curvature?** L† = d∘Xᵗ has symbol t ↦ Σ_k e^k∧Xᵗ(·) applied to ∂_k. It factors as X♯∘d for an algebraic X♯ iff this symbol is well defined on 2-forms. The two writings of e^k∧e^j c, as e^k∧(e^j c) and as −e^j∧(e^k c), must give the same value, i.e. e^k∧Xᵗ(e^j c) + e^j∧Xᵗ(e^k c) = 0. Equivalently, on the constant flat model: P = d∘Xᵗ = Σ_k S_k∂_k gives P(d(f c)) = Σ_{k,j} S_k(e^j c)∂_k∂_j f. Since Hessians are arbitrary, P kills every exact form d(f c) iff the symmetric symbol vanishes. The vanishing includes the diagonal k = j, and is sufficient for P to factor through d; necessity follows from d² = 0. This equivalence is not extended to curved d_B, where d_B² ≠ 0. By H9's transpose identity this is the vanishing of the **symmetrized obstruction**

SO(k, j; c, a) = pair(e^j c, X(e^k∧a)) + pair(e^k c, X(e^j∧a))

vanishes for all k ≤ j, blades c and 1-forms a. Then X♯(e^k∧e^j c) = e^k∧Xᵗ(e^j c), and L_sym = X_sym∘d with X_sym = ½(X + X♯). C1 = 0 implies SO = 0 with X♯ = X.

**H11 — from symbol to operator.** On the flat model C1 = 0 is exactly L = L†. On a curved background the statement holds under these hypotheses:
- the complete bundle map X is parallel for the induced connection, on both form and internal indices (∇^B X = 0);
- the form connection is torsion-free;
- the trace is compatible with the connection;
- boundary terms vanish.

Then d_B∘Xᵗ = Σe^k∧Xᵗ∇_k, and the flat pointwise identity X♯ = X gives L = L† with no remainder: no second covariant derivatives are commuted, so curvature does not enter. Fixed ε alone is insufficient, and covariantly closed Φ is not the same as parallel Φ. Here ∇X = dX + ρ_out(ω)X − Xρ_in(ω), with the form and internal actions taken together. Two cases:
- **Same Spin connection.** When both bundles' connections are induced from the same Spin connection ω, every constant Spin intertwiner, in particular every vector of the universal search, is parallel, curved or not. H11 then applies to the universal C1 kernel too.
- **Independent internal connection or variable coefficients.** For an independent internal connection, as with a general u(A)-valued B, or for variable coefficients, parallelism is an extra condition to check, and it is not implied by Spin-equivariance. Both reviewers checked this hand derivation; it is not computed. Coefficient derivatives (non-parallel Φ, B07-X) are outside scope.

**H12 — the unreduced space.** ad = u(A) ⊂ Cl(p,q). Each blade G_c lies in u(A) after a phase i^{ph(c)} (B02's `_in_u_A` convention). In the real basis e^I ⊗ i^{ph(c)}G_c, the Spin generators ½G_aG_b act by rational matrices, and an algebraic map preserves u(A)-valued forms iff its matrix is real. The search space is **every real Spin(p,q)-equivariant linear map Ω²(u(A)) → Ω^{n−1}(u(A))**: the exact rational nullspace of ρ_out(J)M − Mρ_in(J) = 0. Spin preserves form degree and Clifford grade, so it splits into 25 grade blocks (j → l). Its dimension is fixed in advance by character theory (so(4,ℂ) = sl₂ × sl₂; Λ⁰ = Λ⁴ = (0,0), Λ¹ = Λ³ = (½,½), Λ² = (1,0)+(0,1)): **40**, blockwise. It contains all 20 building blocks of B02's family across bracket modes (which span only 16 dimensions: four exact zero relations). By the Hom-space argument, under the same hypotheses (undressed, real, Spin-equivariant, u(A)-preserving, algebraic), it therefore contains every undressed (9.3)/(8.1) Shiab and every real mixed-mode sum (B07-M). That containment comes from the general argument, not only from testing the 20 blocks. It does **not** contain the raw ordinary-product reading (B07-G). At (3,1), Φ¹ = F, Φ² = 0 and β = e^{01}Γ₀ ∈ u(A) give F∧∗β = e^{023}Id − e^{123}Γ₀₁, whose real identity component lies outside u(A) (Codex's review). Likewise, the complex coefficients in ab = (C − iA)/2 do not lie in the real span. B07-G stays deferred until a specific reality-preserving completion is fixed and checked. It is Spin-equivariant, not U(64,64)-ad-equivariant (neither is the Shiab family); pairings are not varied (B07-Q; both argon reviews: grade-weighted pairings break gauge invariance).

**H13 — the gates and the Einstein condition.** Over a span with basis X₁ … X_N, C1, SO and C2 (N0, N1, N2) are linear in the coefficients, so each gate is an exact kernel. In 4D the curvature response of any equivariant X lies in a four-dimensional space. The response is a 1-form with Clifford values, and Λ¹⊗Λᵏ contains the Ricci-type (1,1) and the scalar (0,0) only for k ∈ {1, 3}, each with multiplicity one: the F and F′ channels. The Weyl type (2,0)+(0,2) does not occur. This grade count is the argument; Weyl absence alone would not suffice. `gates.response` raises if a generator leaves the span, so the computation checks itself:

∗X(ξ(R)) = a E_F(Ric) + b E_{F′}(Ric) + c S E_F(g) + d S E_{F′}(g),

fitted exactly on all 55 Kulkarni–Nomizu generators (which span algebraic curvature, B02) and verified on every one. **Einstein** (B02's κ = ½, nonzero Ricci term) is (a, b) ≠ 0 with c = −a/2, d = −b/2: a linear condition plus a nonvanishing condition. Within a kernel K, the reported Einstein dimension is the rank of (a, b) on the subspace where 2c + a = 2d + b = 0. This is the rank of the response image, not the dimension of the locus of nonzero operators. Order T²: Phase 1 H3 in general form, C2 = ⅓Tr(α∧Xb(T,T)) + ⅓Tr(T∧X(b(α,T) + b(T,α))) − Tr(α∧X(T∧T)); N1/N2 symmetric b; **N0** (the ungraded commutator of the form-valued product): b(T, T) = 0 on the diagonal and its symmetric cross term b(α, T) + b(T, α) = 0, so C2 = −Tr(α∧X(T∧T)). The antisymmetric part need not vanish off the diagonal, and C2 never uses it.

**H14 — the second-order Lagrangian.** I₂ = ⟨Υ, Υ⟩, Υ = X(F_A) + κ₁∗T, metric trace pairing ⟨x, y⟩ = Tr(x∧∗y). X^*X ∝ Id is only a sufficient shortcut: a topological λ∗ in X^*X drops out, since in 4D δ(∗(iK∧a)) = ±∗^{−1}(iK∧iK∧a) = 0 by K∧K = 0 (an off-shell symbol identity, not Bianchi), and a nonzero scalar Id is impossible anyway for a 96-to-64 map by rank. Both are recorded, and only the symbol test supports a conclusion. A common ratio is necessary and sufficient for the flat constant-coefficient kinetic operator to be a multiple of ordinary YM, and that multiple must be nonzero. It does not establish equal actions, which may differ by the topological density, nor curved or nonlinear equivalence. (9.14)'s generalized packaging D* = d_A^*X^*X is a different statement, and the README must keep the two apart. **Exact Fourier test:** for T = t e^{ik·x}, α = a e^{−ik·x} on a flat torus, the action's variation B(a, t) = 2⟨X(−iK∧a) + κ₁∗a, X(iK∧t) + κ₁∗t⟩ is compared, order by order in κ₁, with ⟨a, P t⟩ for explicit operators P built from the codifferential symbol δu = (−1)^m ∗^{−1}(iK∧∗u), X^* (diagonal Gram) and ∗^† — over k ∈ {e_i} ∪ {e_i + e_j}. The κ₁⁰, κ₁¹ and κ₁² parts are **homogeneous** in k of degrees 2, 1 and 0. These n(n+1)/2 vectors determine homogeneous quadratics (exact evaluation rank 10/10 in 4D) and linears (4/4). They would not determine a general inhomogeneous polynomial of degree ≤ 2: 1 − Σk_i + Σ_{i<j}k_ik_j vanishes on all of them. Homogeneity is what makes the test complete.

```python
def _character_dims():
    half = Fraction(1, 2)
    L = {0: [(0, 0)], 1: [(half, half)], 2: [(1, 0), (0, 1)], 3: [(half, half)], 4: [(0, 0)]}

    def cg(a, b):
        out, j = [], abs(a - b)
        while j <= a + b:
            out.append(j)
            j += 1
        return out

    def tens(A, B):
        c = Counter()
        for a1, b1 in A:
            for a2, b2 in B:
                for a in cg(a1, a2):
                    for b in cg(b1, b2):
                        c[(a, b)] += 1
        return c
    out = {}
    for j in range(5):
        for l in range(5):
            X, Y = tens(L[2], L[j]), tens(L[3], L[l])
            d = sum(X[k] * Y[k] for k in X)
            if d:
                out[f"{j},{l}"] = d
    return out
```

```python
Flat model (B = d, eps = 1, constant coefficients; Phase 1 H5 removes the dressing). X: Omega^2 -> Omega^(n-1) is an
algebraic ad-valued map (Clifford coefficients), L = X o d. pair(x, y) = Tr(x ^ y)/2^(n/2) as in Phase 1.

  Wedge transpose  X^t: Omega^1 -> Omega^(n-2),  pair(t, X(beta)) = pair(X^t(t), beta) for every 2-form beta.
  Formal transpose L^dag = d o X^t  (int Tr(T ^ L alpha) = int Tr(alpha ^ L^dag T), compact support; H9).
  Symbol identity  pair(a, e^k ^ X^t(t)) = -pair(t, X(e^k ^ a)), so <a, sigma(L^dag - L)(e^k) t> = -C1(k; t, a).
  The variation of 1/2 int Tr(T ^ L T) is int Tr(alpha ^ L_sym T), L_sym = 1/2 (L + L^dag).
  Factorization (H10): L^dag = X# o d with X# algebraic iff, for all k <= j, blades c and basis 1-forms a,
      SO(k, j; c, a) = pair(e^j c, X(e^k ^ a)) + pair(e^k c, X(e^j ^ a)) = 0;
  then X#(e^k ^ e^j c) = e^k ^ X^t(e^j c), and L_sym = X_sym o d with X_sym = 1/2 (X + X#).
All arithmetic is exact (Gaussian rationals).
"""
from __future__ import annotations

import itertools

from gu.cliffform import GQ, plus, scale
from experiments.B07 import variation as V

# The 20 distinct building blocks of the Shiab family across all bracket modes (B07-M):
# first[m0](Phi1) for m0 in {C, A}, Phi1 in {F, F'}; second[m1 m2](Phi1, Phi2) for m1 m2 in {C, A}^2, Phi2 in {B, B'}.
BLOCKS = tuple([("first", m0, (p1,)) for m0 in "CA" for p1 in ("F", "F'")]
               + [("second", m1 + m2, (p1, p2)) for m1 in "CA" for m2 in "CA" for p1 in ("F", "F'")
                  for p2 in ("B", "B'")])


def block_map(block: tuple, p: int, q: int):
    """The linear map of one building block (the second term without its -1/2)."""
    kind, m, cols = block
    mode = m + "CC" if kind == "first" else "C" + m
    return V.shiab_column(cols, mode, p, q)


def block_name(block: tuple) -> str:
    return f"{block[0]}[{block[1]}]({','.join(block[2])})"


def two_forms(n: int) -> list[dict]:
    return [{((1 << i) | (1 << j), A): GQ(1)} for i, j in itertools.combinations(range(n), 2) for A in range(1 << n)]


def wedge_transpose(X, n: int, eta: list[int]):
    """X^t as a function on 1-forms, built from the dual basis of 2-forms under pair."""
    X, full = V.Linear(X), (1 << n) - 1
    duals = []
    for beta in two_forms(n):
        (G, B), = beta
        d = {(full ^ G, B): GQ(1)}
        v = V.pair(d, beta, eta)
        if v.im != 0 or v.re not in (1, -1):
            raise AssertionError(f"pair is not a signed permutation on basis {(G, B)}: {v}")
        duals.append((beta, scale(d, v.re)))

    def Xt(t: dict) -> dict:
        return plus(*[scale(d, V.pair(t, X(beta), eta)) for beta, d in duals])
    return Xt


def sym_obstruction(X, n: int, eta: list[int]) -> dict:
    """{(k, j, c, a): SO} over k <= j, blades c and basis 1-forms a (index into V.one_forms(n)); nonzero entries only."""
    X, basis = V.Linear(X), V.one_forms(n)
    S = [[X(V.wedge_prod({(1 << k, 0): GQ(1)}, a, eta)) for a in basis] for k in range(n)]
    out = {}
    for k in range(n):
        for j in range(k, n):
            for c in range(1 << n):
                ej, ek = {(1 << j, c): GQ(1)}, {(1 << k, c): GQ(1)}
                for ai in range(len(basis)):
                    v = V.pair(ej, S[k][ai], eta) + V.pair(ek, S[j][ai], eta)
                    if v:
                        out[(k, j, c, ai)] = v
    return out


def sharp(X, n: int, eta: list[int]):

    Xt = wedge_transpose(X, n, eta)

    def Xs(x: dict) -> dict:
        out: dict = {}
        for (f, c), v in x.items():
            k, j = [i for i in range(n) if f >> i & 1]
            img = V.wedge_prod({(1 << k, 0): GQ(1)}, Xt({(1 << j, c): GQ(1)}), eta)
            out = plus(out, scale(img, v))
        return out
    return Xs
```

```python
"""B07 Phase 2, unreduced search: every Spin(p,q)-equivariant real algebraic map X: Omega^2(ad) -> Omega^(n-1)(ad) in 4D.

ad = u(A) inside Cl(p,q) (A the Dirac pairing). Real basis of u(A)-valued k-forms: e^I (x) u_c with u_c = i^{ph(c)} G_c,
ph(c) in {0, 1} the phase that puts the blade in u(A) (B02, tests/test_shiab.py::_in_u_A). In this basis the Spin
generators 1/2 G_a G_b act by rational matrices, and X is u(A)-preserving iff its matrix is real. The equivariant maps
are the exact rational nullspace of rho_out(J) M - M rho_in(J) = 0 over the generators J of spin(p,q). Spin preserves
form degree and Clifford grade, so the space splits over Clifford-grade blocks (j in, l out), solved separately.
All arithmetic is exact (python-flint fmpq_mat; no floats).
"""
from __future__ import annotations

import itertools
from fractions import Fraction

from flint import fmpq, fmpq_mat

from gu.adjoint import from_mono, is_in_algebra
from gu.clifford import dirac_pairing, gammas
from gu.cliffform import GQ, I, blade_to_mono, plus, scale
from gu.shiab import eta_of, generator_action

def phases(p: int, q: int) -> list[int]:
    gs, A = gammas(p, q), from_mono(dirac_pairing(p, q))
    out = []
    for c in range(1 << (p + q)):
        ok = [is_in_algebra(from_mono(blade_to_mono(c, gs).times_i_power(k)), A) for k in (0, 1)]
        if ok.count(True) != 1:
            raise AssertionError(f"blade {c}: u(A) membership {ok}")
        out.append(ok.index(True))
    return out


def basis(n: int, deg: int, grade: int) -> list[tuple[int, int]]:
    """(form mask, blade) pairs of the given form degree and Clifford grade."""
    fs = [sum(1 << i for i in c) for c in itertools.combinations(range(n), deg)]
    cs = [sum(1 << i for i in c) for c in itertools.combinations(range(n), grade)]
    return [(f, c) for f in fs for c in cs]


def to_phased(x: dict, ph: list[int]) -> dict:
    """Coordinates in the e^I (x) u_c basis: v G_c = (v i^{-ph}) u_c."""
    out = {}
    for (f, c), v in x.items():
        w = v * (GQ(0, -1) if ph[c] else GQ(1))
        if w.im:
            raise AssertionError(f"not u(A)-valued at {(f, c)}: {v}")
        out[(f, c)] = Fraction(w.re)
    return out


def from_phased(coords: dict, ph: list[int]) -> dict:
    return plus(*[{k: GQ(v) * (I if ph[k[1]] else GQ(1))} for k, v in coords.items() if v]) if coords else {}


def rho(p: int, q: int, deg: int, grade: int, ph: list[int]) -> list[list[list[Fraction]]]:
    """Matrices of the generators 1/2 G_a G_b (a < b) on the phased basis of one (degree, grade) block."""
    eta, n = eta_of(p, q), p + q
    B = basis(n, deg, grade)
    idx = {k: i for i, k in enumerate(B)}
    mats = []
    for a, b in itertools.combinations(range(n), 2):
        M = [[Fraction(0)] * len(B) for _ in B]
        for col, (f, c) in enumerate(B):
            img = to_phased(generator_action(from_phased({(f, c): Fraction(1)}, ph), a, b, eta), ph)
            for k, v in img.items():
                M[idx[k]][col] += v  # KeyError here would mean Spin mixes blocks
        mats.append(M)
    return mats


def equivariant_block(p: int, q: int, j: int, l: int, ph: list[int]) -> list[dict]:
    """Basis of equivariant maps from (2-forms, grade j) to ((n-1)-forms, grade l), each as {(out_key, in_key): q}."""
    n = p + q
    Bi, Bo = basis(n, 2, j), basis(n, n - 1, l)
    ri, ro = rho(p, q, 2, j, ph), rho(p, q, n - 1, l, ph)
    ni, no = len(Bi), len(Bo)
    unk = lambda r, s: r * ni + s
    rows = []
    for Ri, Ro in zip(ri, ro):
        for r in range(no):
            for s in range(ni):
                row = {}
                for k in range(no):
                    if Ro[r][k]:
                        row[unk(k, s)] = row.get(unk(k, s), 0) + Ro[r][k]
                for k in range(ni):
                    if Ri[k][s]:
                        row[unk(r, k)] = row.get(unk(r, k), 0) - Ri[k][s]
                row = {c: v for c, v in row.items() if v}
                if row:
                    rows.append(row)
    N = no * ni
    if not rows:
        null = [[Fraction(int(i == k)) for i in range(N)] for k in range(N)]
    else:
        A = fmpq_mat(len(rows), N)
        for i, row in enumerate(rows):
            for c, v in row.items():
                A[i, c] = fmpq(v.numerator, v.denominator)
        R, rank = A.rref()
        pivots, r = [], 0
        for c in range(N):
            if r < rank and R[r, c] != 0:
                pivots.append(c)
                r += 1
        free = [c for c in range(N) if c not in set(pivots)]
        null = []
        for fcol in free:
            v = [Fraction(0)] * N
            v[fcol] = Fraction(1)
            for i, pc in enumerate(pivots):
                e = R[i, fcol]
                v[pc] = -Fraction(int(e.p), int(e.q))
            null.append(v)
    return [{(Bo[u // ni], Bi[u % ni]): x for u, x in enumerate(v) if x} for v in null]


def equivariant_basis(p: int, q: int) -> list[dict]:
    ph, n = phases(p, q), p + q
    out = []
    for j in range(n + 1):
        for l in range(n + 1):
            out += equivariant_block(p, q, j, l, ph)
    return out


def as_map(M: dict, p: int, q: int, ph: list[int] | None = None):
    """The basis map M as a function on GQ-coefficient 2-forms (Linear-compatible)."""
    ph = ph or phases(p, q)
    by_in: dict = {}
    for (o, i), v in M.items():
        by_in.setdefault(i, []).append((o, v))

    def X(x: dict) -> dict:
        out: dict = {}
        for (f, c), v in x.items():
            w = v * (GQ(0, -1) if ph[c] else GQ(1))  # coordinate on u_c (complex allowed: complex-linear extension)
            for o, m in by_in.get((f, c), []):
                out = plus(out, {o: w * GQ(m) * (I if ph[o[1]] else GQ(1))})
        return out
    return X


def matrix_of(X, p: int, q: int, ph: list[int] | None = None) -> dict:
    """{(out_key, in_key): rational} of X in the phased real basis; raises if X does not preserve u(A)."""
    ph, n = ph or phases(p, q), p + q
    out = {}
    for j in range(n + 1):
        for k in basis(n, 2, j):
            img = X(from_phased({k: Fraction(1)}, ph))
            for o, v in (to_phased(img, ph) if img else {}).items():
                out[(o, k)] = v
    return out


def block_dims(p: int, q: int) -> dict:
    """{"j,l": dim} of the equivariant maps from Clifford grade j to grade l (nonzero blocks only)."""
    ph, n = phases(p, q), p + q
    out = {}
    for j in range(n + 1):
        for l in range(n + 1):
            d = len(equivariant_block(p, q, j, l, ph))
            if d:
                out[f"{j},{l}"] = d
    return out
```

```python
"""B07 Phase 2 gates on a linear span of algebraic maps X: C1, SO, C2 under N0/N1/N2, and the curvature response.

C2 (Phase 1 H3, general form): C2 = 1/3 Tr(alpha ^ X b(T,T)) + 1/3 Tr(T ^ X(b(alpha,T) + b(T,alpha))) - Tr(alpha ^ X(T^T)).
    N1, N2: b symmetric on 1-forms (Phase 1 `variation.c2_value`); N0: b == 0, so C2 = -Tr(alpha ^ X(T^T)).
Curvature response (B02 closed-form basis; 4D): *X(xi(R)) = a E_F(Ric) + b E_F'(Ric) + c S E_F(g) + d S E_F'(g),
    fitted exactly on all Kulkarni-Nomizu generators and verified on every one (a residual is an error, not a fit).
    Einstein (B02's ratio kappa = 1/2): (a, b) != (0, 0), c = -a/2, d = -b/2.
All arithmetic is exact (Gaussian rationals; sympy Rational for kernels).
"""
from __future__ import annotations

from fractions import Fraction

import numbers

import numpy as np
import sympy as sp

from gu.cliffform import GQ, plus, scale, star
from gu.curvature import kulkarni_nomizu, ricci, scalar
from gu.shiab import embed_tensor, eta_of, xi
from experiments.B02.response import spanning_pairs, sym_basis
from experiments.B07 import variation as V

NORMS = ("N0", "N1", "N2")


def exact(x):
    """An exact scalar as a sympy expression; rejects Python, numpy and sympy floats anywhere in it (P4). Fixed-width
    numpy integers are exact: they are converted to Python int before any arithmetic."""
    if isinstance(x, numbers.Integral):
        x = int(x)
    elif isinstance(x, (float, complex, np.generic)):
        raise TypeError(f"inexact scalar: {x!r}")
    x = sp.sympify(x)
    if x.has(sp.Float):
        raise TypeError(f"inexact scalar: {x!r}")
    return sp.expand(x)


def gq(x) -> GQ:
    """Exact Gaussian rational -> GQ; rejects floats (before any simplification) and non-Gaussian-rationals."""
    x = exact(x)
    re, im = sp.re(x), sp.im(x)
    if not (re.is_Rational and im.is_Rational):
        raise TypeError(f"not a Gaussian rational: {x}")
    return GQ(Fraction(int(re.p), int(re.q)), Fraction(int(im.p), int(im.q)))


def combine(maps: list, vec: list):
    """sum_i vec[i] * maps[i] as one map."""
    terms = [(m, c) for m, c in ((m, gq(c)) for m, c in zip(maps, vec)) if c]
    return lambda x: plus(*[scale(m(x), c) for m, c in terms]) if terms else {}


def c2_value(X, alpha: dict, T: dict, norm: str, eta: list[int]) -> GQ:
    if norm == "N0":
        return GQ() - V.pair(alpha, X(V.wedge_prod(T, T, eta)), eta)
    return V.c2_value(X, alpha, T, norm, eta)


def c2_residual(X, n: int, eta: list[int], norm: str) -> dict:
    """{(a, i, j): polarized C2} as in Phase 1 `variation.c2_residual`, for N0, N1 or N2."""
    if norm not in NORMS:
        raise ValueError("norm must be N0, N1 or N2")
    X, basis = V.Linear(X), V.one_forms(n)
    diag = [[c2_value(X, al, t, norm, eta) for t in basis] for al in basis]
    out = {}
    for a, al in enumerate(basis):
        for i in range(len(basis)):
            if diag[a][i]:
                out[(a, i, i)] = diag[a][i]
            for j in range(i + 1, len(basis)):
                v = c2_value(X, al, plus(basis[i], basis[j]), norm, eta) - diag[a][i] - diag[a][j]
                if v:
                    out[(a, i, j)] = v
    return out


def response(X, p: int, q: int) -> list:
    """Exact (a, b, c, d); raises if the response is not in the four-dimensional span on some generator."""
    eta, n = eta_of(p, q), p + q
    g = np.diag(eta).astype(np.int64)
    sym = sym_basis(n)
    rows, rhs = [], []
    for s, t in spanning_pairs(n):
        R = kulkarni_nomizu(sym[s], sym[t])
        Ric, S = ricci(R, eta), Fraction(int(scalar(R, eta)))
        basis = [embed_tensor(Ric, 1, 0, p, q), embed_tensor(Ric, 0, 1, p, q),
                 scale(embed_tensor(g, 1, 0, p, q), S), scale(embed_tensor(g, 0, 1, p, q), S)]
        got = star(X(xi(R, eta)), eta)
        for k in set(got) | {k for b in basis for k in b}:
            rows.append([V._sym(b.get(k, GQ())) for b in basis])
            rhs.append(V._sym(got.get(k, GQ())))
    sol, params = sp.Matrix(rows).gauss_jordan_solve(sp.Matrix(rhs))  # raises ValueError if inconsistent
    if params.shape[0]:
        raise AssertionError("response basis not independent on the generators")
    return [exact(x) for x in sol]


def is_einstein(r: list) -> bool:
    """B02 kappa = 1/2 with a nonzero Ricci term: 2c + a = 0, 2d + b = 0, (a, b) != 0 (exact; no division)."""
    a, b, c, d = (exact(x) for x in r)
    return (a != 0 or b != 0) and 2 * c + a == 0 and 2 * d + b == 0


def gate_survey(maps: list, p: int, q: int, norms=NORMS) -> dict:
    """Kernels of C1, SO and C1 + C2 (per norm) over span(maps), with responses of every kernel basis vector."""
    from experiments.B07.phase2 import symmetric as Sy
    eta, n = eta_of(p, q), p + q
    c1 = {i: V.c1_residual(m, n, eta) for i, m in enumerate(maps)}
    so = {i: Sy.sym_obstruction(m, n, eta) for i, m in enumerate(maps)}
    K1, KS = V.kernel(c1), V.kernel(so)
    R1 = [response(combine(maps, v), p, q) for v in K1]
    out = {"dim": len(maps), "c1_kernel_dim": len(K1), "so_kernel_dim": len(KS),
           "c1_kernel_responses": [[str(x) for x in r] for r in R1],
           "c1_kernel_einstein_dim": _einstein_dim(R1), "joint": {}}
    k1maps = [combine(maps, v) for v in K1]
    for norm in norms:
        c2 = {i: c2_residual(m, n, eta, norm) for i, m in enumerate(k1maps)}
        J = V.kernel(c2) if K1 else []
        RJ = [[sum(x * r[k] for x, r in zip(w, R1)) for k in range(4)] for w in J]
        out["joint"][norm] = {"dim": len(J), "responses": [[str(x) for x in r] for r in RJ],
                              "einstein_dim": _einstein_dim(RJ)}
    return out


def _einstein_dim(R: list) -> int:
    """dim of {kernel vectors whose response satisfies 2c + a = 0, 2d + b = 0} minus dim of those with a = b = 0.

    > 0 iff the kernel contains an Einstein operator (B02 kappa = 1/2, nonzero Ricci term)."""
    if not R:
        return 0
    R = [[exact(x) for x in r] for r in R]
    M = sp.Matrix([[2 * r[2] + r[0] for r in R], [2 * r[3] + r[1] for r in R]])
    lin = M.nullspace()
    if not lin:
        return 0
    L = sp.Matrix.hstack(*lin)
    ab = sp.Matrix([[r[0] for r in R], [r[1] for r in R]]) * L
    return len(lin) - len(ab.nullspace())
```

```python
"""B07 Phase 2, item 2: the variation of the second-order Lagrangian (9.11) against the printed (9.12)-(9.15).

I2 = <U, U>, U = X(F_A) + kappa * T (9.7), with the metric trace pairing <x, y> = Tr(x ^ *y)/2^(n/2) (`mpair`),
eps and the metric fixed, delta T = alpha. Flat model, linear order in T: U_lin(T) = X(dT) + kappa *T.

Exact Fourier test (H14). For T = t e^{i k.x} and alpha = a e^{-i k.x} on a flat torus, d -> i K ^ (K = sum k_i e^i),
and the first variation of the quadratic part of I2 is the bilinear form
    B(a, t) = 2 <X(-i K ^ a) + kappa *a, X(i K ^ t) + kappa *t>,
computed from the action alone (no adjoints). It is compared with <a, P t> for explicit operators P assembled from
    delta (codifferential, symbol on m-forms: u -> (-1)^m *^{-1}(i K ^ *u)), X* (metric adjoint via the diagonal Gram
    matrix of basis forms), *^{-1}, and *^dag (metric adjoint of *, explicit),
term by term and order by order in kappa, over k in {e_i} and {e_i + e_j}. The kappa^0, kappa^1, kappa^2 parts are
homogeneous in k of degree 2, 1, 0, and these vectors determine homogeneous forms of degree <= 2 (they would not
determine a general inhomogeneous polynomial of degree 2).
Conventions: "pinned" (* of gu.forms; a ^ *b = <a, b> vol) and "prime" (*' = (-1)^deg *, with its own pairing).
"""
from __future__ import annotations

import itertools

from gu.cliffform import GQ, plus, scale, star
from experiments.B07 import variation as V

I = GQ(0, 1)


def star_c(x: dict, eta: list[int], conv: str) -> dict:
    if conv == "pinned":
        return star(x, eta)
    if conv == "prime":
        return plus(*[{k: v * (-1) ** k[0].bit_count()} for k, v in star(x, eta).items()]) if x else {}
    raise ValueError(conv)


def mpair(x: dict, y: dict, eta: list[int], conv: str) -> GQ:
    """<x, y>_conv = Tr(x ^ *_conv y)/2^(n/2)."""
    return V.pair(x, star_c(y, eta, conv), eta)


def forms(n: int, deg: int, scalar_only: bool = False) -> list[dict]:
    blades = [0] if scalar_only else range(1 << n)
    return [{(sum(1 << i for i in c), A): GQ(1)} for c in itertools.combinations(range(n), deg) for A in blades]


def adjoint(Y, n: int, deg_in: int, deg_out: int, eta: list[int], conv: str):
    """Metric adjoint Y*: Omega^deg_out -> Omega^deg_in of Y: Omega^deg_in -> Omega^deg_out (diagonal Gram)."""
    Y, basis = V.Linear(Y), forms(n, deg_in)
    gram = []
    for b in basis:
        g = mpair(b, b, eta, conv)
        if g.im != 0 or g.re not in (1, -1):
            raise AssertionError(f"Gram is not diagonal +-1 at {b}: {g}")
        gram.append((b, g.re))

    def Ys(u: dict) -> dict:
        return plus(*[scale(b, mpair(Y(b), u, eta, conv) * GQ(g)) for b, g in gram])
    return Ys


def star_inv(x: dict, eta: list[int], conv: str) -> dict:
    """*^{-1} by the computed square of * on each homogeneous basis element."""
    out: dict = {}
    for k, v in x.items():
        e = {k: GQ(1)}
        ss = star_c(star_c(e, eta, conv), eta, conv)
        (k2, w), = ss.items()
        assert k2 == k and w.im == 0 and w.re in (1, -1)
        out = plus(out, scale(star_c(e, eta, conv), v * w))
    return out


def star_adjoint_sign(p: int, q: int, k: int, conv: str) -> int:
    """s with *^dag = s * from Omega^(n-k) to Omega^k, checked on every basis pair (scalar Clifford factor: * acts on
    the form factor only, so the sign does not depend on the Clifford coefficient)."""
    eta, n = V.eta_of(p, q), p + q
    signs = set()
    for a in forms(n, k, scalar_only=True):
        for u in forms(n, n - k, scalar_only=True):
            l, r = mpair(star_c(a, eta, conv), u, eta, conv), mpair(a, star_c(u, eta, conv), eta, conv)
            if l or r:
                signs.add(int(l.re * r.re))
    assert len(signs) == 1, signs
    return signs.pop()


def mass_sign(p: int, q: int, conv: str) -> int:
    """t with *^dag * = t Id on 1-forms."""
    eta, n = V.eta_of(p, q), p + q
    signs = {int(mpair(star_c(a, eta, conv), star_c(a, eta, conv), eta, conv).re * mpair(a, a, eta, conv).re)
             for a in forms(n, 1, scalar_only=True)}
    assert len(signs) == 1, signs
    return signs.pop()


def wavevectors(n: int) -> list[list[int]]:
    return [[int(i == a) for i in range(n)] for a in range(n)] + \
           [[int(i in (a, b)) for i in range(n)] for a, b in itertools.combinations(range(n), 2)]


def fourier_terms(X, p: int, q: int, kv: list[int], conv: str) -> dict:
    """Matrices {name: {(ai, ti): GQ}} over basis 1-forms a, t, for one wavevector kv.

    action_k0/k1/k2: kappa^0, kappa^1, kappa^2 parts of B(a, t);
    printed_1..4: <a, 2 * term> for (9.13)'s terms, term 2 repaired by inserting * (literal term 2 is ill-typed);
    derived_3, derived_4: <a, 2 * kappa *^dag X(i K ^ t)> and <a, 2 * kappa^2 *^dag * t> (kappa set to 1).
    """
    eta, n = V.eta_of(p, q), p + q
    X = V.Linear(X)
    Xs = adjoint(X, n, 2, n - 1, eta, conv)
    Sd = adjoint(lambda x: star_c(x, eta, conv), n, 1, n - 1, eta, conv)
    K = {(1 << i, 0): GQ(c) for i, c in enumerate(kv) if c}

    def dsym(u, sgn):  # symbol of d on e^{sgn i k.x}
        return scale(V.wedge_prod(K, u, eta), I * GQ(sgn))

    def delta(u, deg):  # symbol of the codifferential on m-forms, e^{+i k.x}
        return scale(star_inv(dsym(star_c(u, eta, conv), 1), eta, conv), GQ((-1) ** deg))

    basis = V.one_forms(n)
    out = {name: {} for name in ("action_k0", "action_k1", "action_k2", "printed_1", "printed_2", "printed_3",
                                 "printed_4", "derived_3", "derived_4")}
    for ti, t in enumerate(basis):
        Xdt = X(dsym(t, 1))
        st = star_c(t, eta, conv)
        P = {"printed_1": delta(Xs(Xdt), 2), "printed_2": delta(Xs(st), 2), "printed_3": star_c(Xdt, eta, conv),
             "printed_4": t, "derived_3": Sd(Xdt), "derived_4": Sd(st)}
        for ai, a in enumerate(basis):
            Xda = X(dsym(a, -1))
            sa = star_c(a, eta, conv)
            vals = {"action_k0": mpair(Xda, Xdt, eta, conv) * GQ(2),
                    "action_k1": (mpair(Xda, st, eta, conv) + mpair(sa, Xdt, eta, conv)) * GQ(2),
                    "action_k2": mpair(sa, st, eta, conv) * GQ(2)}
            vals.update({nm: mpair(a, u, eta, conv) * GQ(2) for nm, u in P.items()})
            for nm, v in vals.items():
                if v:
                    out[nm][(ai, ti)] = v
    return out


def lin(*terms) -> dict:
    """Sum of (coefficient, matrix) pairs."""
    out: dict = {}
    for c, m in terms:
        for k, v in m.items():
            w = out.get(k, GQ()) + v * GQ(c)
            if w:
                out[k] = w
            else:
                out.pop(k, None)
    return out


def compare(X, p: int, q: int, conv: str) -> dict:
    """Which printed/derived combinations equal the action's variation, over all wavevectors."""
    checks = {"kappa0: action == printed_1": lambda m: lin((1, m["action_k0"]), (-1, m["printed_1"])),
              "kappa1: action == printed_2 + printed_3": lambda m: lin((1, m["action_k1"]), (-1, m["printed_2"]),
                                                                        (-1, m["printed_3"])),
              "kappa1: action == printed_2 + derived_3": lambda m: lin((1, m["action_k1"]), (-1, m["printed_2"]),
                                                                        (-1, m["derived_3"])),
              "kappa2: action == printed_4": lambda m: lin((1, m["action_k2"]), (-1, m["printed_4"])),
              "kappa2: action == derived_4": lambda m: lin((1, m["action_k2"]), (-1, m["derived_4"])),
              "derived_3 == -printed_3": lambda m: lin((1, m["derived_3"]), (1, m["printed_3"])),
              "derived_4 == -printed_4": lambda m: lin((1, m["derived_4"]), (1, m["printed_4"]))}
    res = {name: True for name in checks}
    nonvacuous = {name: False for name in ("printed_1", "printed_2", "printed_3", "printed_4")}
    for kv in wavevectors(p + q):
        m = fourier_terms(X, p, q, kv, conv)
        for name, f in checks.items():
            res[name] &= not f(m)
        for name in nonvacuous:
            nonvacuous[name] |= bool(m[name])
    return {"signature": [p, q], "conv": conv, "checks": res, "nonvacuous": nonvacuous}


def ym_symbol(X, p: int, q: int, conv: str = "pinned") -> dict:
    """Is the kappa^0 kinetic symbol a -> delta X*X(iK ^ a) one scalar multiple of the ordinary Yang-Mills symbol
    a -> delta(iK ^ a), for every wavevector? This is the (9.14) Yang-Mills reading at principal-symbol level. In 4D a
    term lambda * in X*X drops out: delta(*(iK ^ a)) = +-*^{-1}(iK ^ iK ^ a) = 0 since K ^ K = 0. So, unlike X*X ~ Id,
    one common nonzero ratio is necessary and sufficient for the flat constant-coefficient quadratic kinetic operator
    to be a multiple of ordinary Yang-Mills (not for equality of actions, nor for curved or nonlinear equations).
    Ratios over all nonzero YM entries; a nonzero entry where the YM symbol vanishes is a mismatch. Both symbols are
    homogeneous quadratics in k, so a shared ratio on these wavevectors holds for all k. Codifferential symbol as in
    `fourier_terms` (degree 2)."""
    eta, n = V.eta_of(p, q), p + q
    X = V.Linear(X)
    Xs = adjoint(X, n, 2, n - 1, eta, conv)

    def delta2(u):
        return star_inv(scale(V.wedge_prod(K, star_c(u, eta, conv), eta), I), eta, conv)

    ratios, mismatches = set(), 0
    for kv in wavevectors(n):
        K = {(1 << i, 0): GQ(c) for i, c in enumerate(kv) if c}
        for t in V.one_forms(n):
            dt = scale(V.wedge_prod(K, t, eta), I)
            sx, s0 = delta2(Xs(X(dt))), delta2(dt)
            for key in set(sx) | set(s0):
                u, v = sx.get(key, GQ()), s0.get(key, GQ())
                if not v:
                    mismatches += bool(u)
                    continue
                w, m = u * GQ(v.re, -v.im), v.re ** 2 + v.im ** 2
                ratios.add(str(GQ(w.re / m, w.im / m)))
    return {"signature": [p, q], "conv": conv, "ratios": sorted(ratios), "mismatches": mismatches,
            "ym_proportional": mismatches == 0 and len(ratios) == 1 and str(GQ()) not in ratios}


def xstar_x(X, p: int, q: int, conv: str = "pinned") -> dict:
    """Is X* X a multiple of the identity on ad-valued 2-forms? (the (9.14) Yang-Mills reading)."""
    eta, n = V.eta_of(p, q), p + q
    X = V.Linear(X)
    Xs = adjoint(X, n, 2, n - 1, eta, conv)
    ratios, offdiag = set(), 0
    for b in forms(n, 2):
        img = Xs(X(b))
        (k,) = b
        rest = {kk: v for kk, v in img.items() if kk != k}
        offdiag += bool(rest)
        ratios.add(str(img.get(k, GQ())))
    return {"signature": [p, q], "diagonal_values": sorted(ratios), "offdiagonal_rows": offdiag,
            "multiple_of_identity": offdiag == 0 and len(ratios) == 1}
```

```python
def dirty_paths(porcelain_z: str) -> list[str]:
    """Paths in `git status --porcelain=v1 -z` output other than the exempt output. A rename/copy record (R or C in
    either status column) is followed by an unprefixed source-path record, which is consumed and checked too."""
    entries, dirty = iter(porcelain_z.split("\0")), []
    for e in entries:
        if not e:
            continue
        if set(e[:2]) & set("RC"):
            src = next(entries)
            if src != OUT_REL:
                dirty.append(src)
        if e[3:] != OUT_REL:
            dirty.append(e[3:])
    return dirty


def git_commit() -> str:
    out = subprocess.run(["git", "status", "--porcelain=v1", "-z", "--untracked-files=all", "--", *PRODUCERS],
                         capture_output=True, text=True, check=True).stdout
    dirty = dirty_paths(out)
    if dirty:
        raise SystemExit("uncommitted producing code or inputs:\n" + "\n".join(dirty))
    return subprocess.run(["git", "rev-parse", "HEAD"], capture_output=True, text=True, check=True).stdout.strip()


def rank(mats: list[dict]) -> int:
    keys = sorted({k for m in mats for k in m})
    if not keys:
        return 0
    ix = {k: i for i, k in enumerate(keys)}
    A = fmpq_mat(len(keys), len(mats))
    for j, m in enumerate(mats):
        for k, v in m.items():
            A[ix[k], j] = fmpq(v.numerator, v.denominator)
    return A.rank()


def e_op(p: int, q: int):
    ms = [(Sy.block_map(b, p, q), c) for b, c in E_OP]
    return lambda x: plus(*[scale(m(x), c) for m, c in ms])


def independent_blocks(p: int, q: int) -> tuple[list, int]:
    """A maximal independent subset of the 20 blocks (greedy, in BLOCKS order) and the number of zero relations."""
    ph, chosen, mats = U.phases(p, q), [], []
    for b in Sy.BLOCKS:
        m = U.matrix_of(Sy.block_map(b, p, q), p, q, ph)
        if rank(mats + [m]) > len(mats):
            chosen.append(b)
            mats.append(m)
    return chosen, len(Sy.BLOCKS) - len(chosen)


def item1_4d(p: int, q: int) -> dict:
    ph = U.phases(p, q)
    basis = U.equivariant_basis(p, q)
    umaps = [U.as_map(M, p, q, ph) for M in basis]
    blocks, relations = independent_blocks(p, q)
    bmats = [U.matrix_of(Sy.block_map(b, p, q), p, q, ph) for b in blocks]
    out = {"signature": [p, q],
           "universal_dim": len(basis),
           "universal_block_dims": U.block_dims(p, q),
           "blocks_rank": len(blocks), "block_zero_relations": relations,
           "blocks_in_universal_span": rank(basis + bmats) == len(basis),
           "blocks": G.gate_survey([Sy.block_map(b, p, q) for b in blocks], p, q),
           "universal": G.gate_survey(umaps, p, q)}
    out["blocks"]["names"] = [Sy.block_name(b) for b in blocks]
    out["e_op_response"] = [str(x) for x in G.response(e_op(p, q), p, q)]
    out["e_op_c1_nonzero"] = len(V.c1_residual(e_op(p, q), p + q, V.eta_of(p, q)))
    return out


def e_op_witnesses(p: int, q: int) -> dict:
    """Bounded searches at 14D for the block representative E_OP: C1 (counterexample or none found) and C2/N0-N2."""
    eta, n = V.eta_of(p, q), p + q
    X = V.Linear(e_op(p, q))
    r = range(5)
    blades = [0] + [1 << i for i in r] + [(1 << i) | (1 << j) for i, j in itertools.combinations(r, 2)]
    c1 = None
    checked = 0
    for k, i, j, A, B in itertools.product(range(3), range(5), range(5), blades, blades):
        checked += 1
        v = V.c1_entry(X, k, {(1 << i, A): GQ(1)}, {(1 << j, B): GQ(1)}, eta)
        if v:
            c1 = {"k": k, "t": [i, A], "a": [j, B], "value": [str(v.re), str(v.im)]}
            break
    c2 = {}
    small = [{(1 << i, A): GQ(1)} for i in range(3) for A in blades]
    for norm in G.NORMS:
        c2[norm] = None
        for (ai, al), (ti, t), (si, s) in itertools.product(enumerate(small), enumerate(small), enumerate(small)):
            if si < ti:
                continue
            T = t if si == ti else plus(t, s)
            v = G.c2_value(X, al, T, norm, eta)
            if si != ti:
                v = v - G.c2_value(X, al, t, norm, eta) - G.c2_value(X, al, s, norm, eta)
            if v:
                c2[norm] = {"alpha": ai, "t": ti, "s": si, "value": [str(v.re), str(v.im)]}
                break
    return {"signature": [p, q], "c1_entries_checked": checked, "c1_witness": c1, "c2_witness": c2}


def item2() -> dict:
    signs = [{"signature": [p, n - p], "conv": conv, "star_dag_sign_1form": SO2.star_adjoint_sign(p, n - p, 1, conv),
              "mass_sign": SO2.mass_sign(p, n - p, conv)}
             for n in (4, 14) for p in range(n + 1) for conv in ("pinned", "prime")]
    maps = {name: (lambda name: lambda p, q: V.branch_map(name, p, q))(name) for name in V.BRANCHES}
    maps["E_OP block representative"] = e_op
    fourier = [dict(SO2.compare(f(p, q), p, q, conv), map=name)
               for name, f in maps.items() for p, q in [(3, 1), (1, 3), (2, 2), (4, 0)] for conv in ("pinned", "prime")]
    xx = [dict(SO2.xstar_x(f(p, q), p, q), map=name) for name, f in maps.items() for p, q in SIGS_4D]
    ym = [dict(SO2.ym_symbol(f(p, q), p, q), map=name) for name, f in maps.items() for p, q in SIGS_4D]
    return {"star_signs": signs, "fourier": fourier, "xstar_x": xx, "ym_symbol": ym}
```
