## The mathematics being tested

**E1, the reduction.**
- With U = X(F) + κ∗T, (9.11) at T = 0 is ⟨X(F), X(F)⟩, with the bilinear metric trace pairing `mpair` of `second_order`. It is not a Hermitian norm, so positivity is not inferred.
- On the flat model with F = ξ(R) for algebraic R, this is a quadratic form Q_X on the 20-dimensional space 𝓡 of algebraic curvature tensors at a point. For Spin-equivariant X, Q_X is Spin-invariant.
- **Completeness of the four invariants.** In 4D Lorentzian signature, 𝓡 = (scalar) ⊕ (trace-free Ricci) ⊕ (Weyl), irreducible real summands. The real Weyl representation is the realification of a complex irreducible (W⁺, with W⁻ its conjugate), so it carries exactly two real invariant quadratic forms, W·W and W·∗W. Each of the other summands carries one, and distinct summands do not pair invariantly. So the four invariants span all invariant quadratic forms.
- The fit is overdetermined: 210 bilinear equations in 4 unknowns. A consistent fit is the theorem at identity scope. An inconsistent fit is recorded, not raised, which is what happens for non-equivariant (dressed) X.
- ∗W is the last-pair dual (∗W)_abcd = ½ε_cd^{fg}W_abfg, with ε₀₁₂₃ = +1.

**E1, the response route.**
- For C1-surviving X, ∗X(ξR) lies in the span of the four B02 response maps (`gates.response`), so Q_X = Σ rᵢrⱼGᵢⱼ.
- This gives the Einstein-ratio identity, and covers the whole C1 kernel without rebuilding the 40-dimensional basis.
- The six zero-response directions give X(ξR) = 0, so they and all their cross terms contribute 0.

**E2, the identity.**
- For invertible h acting on the Clifford factor (B02 `proofs.md`): ⊚_{εh}(c_h x) = c_h ⊚_ε(x), with c_h x = h⁻¹xh.
- At ε = 1: ⊚_h(c_h ξW) = c_h ⊚(ξW) = 0. This is the covariance control.
- Equivalently ⊚_h(x) = c_h ⊚(c_h⁻¹x), so ⊚_h(x) = 0 ⟺ c_h⁻¹x ∈ ker ⊚. Since c_h⁻¹ acts on the Clifford factor only, c_h⁻¹ξW is in general not in ξ(Weyl) and may have other Clifford grades, so nothing forces it into ker ⊚.

**E2, grade-2 Cayley elements lie in Spin.**
- For a simple bivector G_I with G_I² = s ∈ {±1} and real t, X = tG_I gives h = (1 − X)²/(1 − t²s) = α + βG_I with α = (1 + t²s)/(1 − t²s) and β = −2t/(1 − t²s).
- Then h h̃ = α² − β²s = 1, using G̃_I = −G_I.
- h is even, and h v h⁻¹ is a vector for every vector v, because G_I is a bivector.
- Hence h is in the Spin image. At t = ½ the path from t = 0 does not cross the pole at t = ±1, so h lies in the identity component.
- Codex verified this independently at t = ½.

**E2, residual symmetry.**
- The stabilizer is {L ∈ spin(p,q) : ρ(L)⊚_h = ⊚_h ρ(L) on ξ(𝓡)}, computed as 6 − rank of the stacked commutator columns.
- By equivariance it contains the centralizer {L : [L, h] = 0}.
- Task 4 computes the centralizer independently. Equal dimensions, together with this inclusion, give equality on the checked members.

`experiments/B07/escape/quadratic.py`:
```python
"""E1: the curvature sector of the second-order Lagrangian (9.11) at a 4D point (flat model, T = 0).

I2 = <U, U> with U = X(F) + kappa *T (`second_order`). At T = 0 and F = xi(R) for algebraic curvature R this is the
quadratic form Q_X(R) = <X(xi R), X(xi R)>, with the metric trace pairing `mpair` (both Hodge conventions).
Q_X is fitted, as a bilinear form on a basis of the 20-dimensional space of algebraic curvature tensors, to the four
Spin(p,q)-invariant bilinear forms W.W, W.*W, Ric0.Ric0 and S S. Identity scope: all basis pairs (i <= j), exact.
An inconsistent fit is recorded as such (not raised): a non-equivariant X, e.g. a dressed one, need not fit.
"""
from __future__ import annotations

import functools
import itertools
from fractions import Fraction

import numpy as np
import sympy as sp
from flint import fmpq, fmpq_mat

from gu.cliffform import GQ
from gu.curvature import decompose, kulkarni_nomizu, ricci, scalar
from gu.shiab import xi
from experiments.B02.response import spanning_pairs, sym_basis
from experiments.B07.phase2 import second_order as SO2

INVARIANTS = ("W.W", "W.*W", "Ric0.Ric0", "S.S")


def _q(x) -> Fraction:
    """Exact coercion (P4): integers (Python or numpy) and Fractions only; everything else raises TypeError."""
    if isinstance(x, (bool, np.bool_)) or not isinstance(x, (int, np.integer, Fraction)):
        raise TypeError(f"inexact or non-numeric entry {x!r}")
    return Fraction(int(x)) if isinstance(x, (int, np.integer)) else x


def independent(tensors: list[np.ndarray]) -> list[int]:
    """Indices of a maximal independent subset (greedy, in order) of integer tensors, by exact rank."""
    chosen: list[int] = []
    flat = [t.reshape(-1) for t in tensors]
    for i in range(len(flat)):
        rows = [flat[j] for j in chosen + [i]]
        M = fmpq_mat(len(rows), len(rows[0]), [fmpq(f.numerator, f.denominator) for r in rows for f in map(_q, r)])
        if M.rank() == len(rows):
            chosen.append(i)
    return chosen


def curvature_basis(n: int) -> list[np.ndarray]:
    """A basis of algebraic curvature tensors: an independent subset of the B02 spanning set KN(h_s, h_t)."""
    sym = sym_basis(n)
    span = [kulkarni_nomizu(sym[s], sym[t]) for s, t in spanning_pairs(n)]
    return [span[i] for i in independent(span)]


def _levi(idx: tuple) -> int:
    if len(set(idx)) < len(idx):
        return 0
    s = 1
    for i, j in itertools.combinations(range(len(idx)), 2):
        if idx[i] > idx[j]:
            s = -s
    return s


def parts(R: np.ndarray, eta: list[int]) -> tuple:
    """(W, Ric0, S) as exact Fraction arrays (W = Weyl part, Ric0 = trace-free Ricci)."""
    n = len(eta)
    sp_ = decompose(R, eta)
    den = _q(sp_.denominator)
    W = np.vectorize(lambda v: _q(v) / den, otypes=[object])(sp_.weyl)
    S = Fraction(int(scalar(R, eta)))
    Ric = np.vectorize(_q, otypes=[object])(ricci(R, eta))
    Ric0 = Ric - np.diag([S * e for e in eta]).astype(object) / n
    return W, Ric0, S


def invariant_bilinears(R1: np.ndarray, R2: np.ndarray, eta: list[int]) -> list[Fraction]:
    """[W1.W2, W1.*W2, Ric0_1.Ric0_2, S1 S2], all indices contracted with eta (4D only for W.*W).

    *W is the last-pair Hodge dual (1/2) eps_cd^fg W_abfg with eps_0123 = +1."""
    n = len(eta)
    if n != 4:
        raise ValueError("4D only")
    (W1, A1, S1), (W2, A2, S2) = parts(R1, eta), parts(R2, eta)
    e = eta
    ww = sum(W1[a, b, c, d] * W2[a, b, c, d] * e[a] * e[b] * e[c] * e[d]
             for a, b, c, d in itertools.product(range(n), repeat=4))
    # W1.*W2 with (*W)_abcd = (1/2) eps_cd^fg W_abfg (last-pair Hodge dual); the sum runs over both f, g orders.
    wsw = Fraction(1, 2) * sum(W1[a, b, c, d] * _levi((c, d, f, g)) * e[c] * e[d] * W2[a, b, f, g] * e[a] * e[b] * e[f] * e[g]
              for a, b, c, d, f, g in itertools.product(range(n), repeat=6) if _levi((c, d, f, g)))
    rr = sum(A1[a, b] * A2[a, b] * e[a] * e[b] for a, b in itertools.product(range(n), repeat=2))
    return [Fraction(ww), Fraction(wsw), Fraction(rr), S1 * S2]


@functools.lru_cache(maxsize=None)
def _setup(p: int, q: int):
    """(basis, invariant rows over basis pairs i <= j), cached per signature."""
    eta = [1] * p + [-1] * q
    basis = curvature_basis(p + q)
    pairs = list(itertools.combinations_with_replacement(range(len(basis)), 2))
    rows = [[sp.Rational(x.numerator, x.denominator) for x in invariant_bilinears(basis[i], basis[j], eta)]
            for i, j in pairs]
    return basis, pairs, sp.Matrix(rows)


def bilinear_fit(f, g, p: int, q: int, conv: str = "pinned") -> dict:
    """Fit B(R, R') = <f(R), g(R')> on all basis pairs (i <= j) to the invariant bilinears.

    f, g: algebraic curvature -> form. Returns {"re": coeffs | None, "im": coeffs | None} (None = not in the span)."""
    eta = [1] * p + [-1] * q
    basis, pairs, A = _setup(p, q)
    fs, gs = [f(R) for R in basis], [g(R) for R in basis]
    re, im = [], []
    for i, j in pairs:
        v = SO2.mpair(fs[i], gs[j], eta, conv) if fs[i] and gs[j] else GQ()
        re.append(sp.Rational(v.re.numerator, v.re.denominator))
        im.append(sp.Rational(v.im.numerator, v.im.denominator))
    out = {}
    for part, rhs in (("re", re), ("im", im)):
        try:
            sol, params = A.gauss_jordan_solve(sp.Matrix(rhs))
        except ValueError:
            out[part] = None
            continue
        if params.shape[0]:
            raise AssertionError("invariant bilinears are not independent on the basis")
        out[part] = [str(x) for x in sol]
    return out


def quadratic_form(X, p: int, q: int, conv: str = "pinned") -> dict:
    """Q_X fitted to INVARIANTS (identity scope on the 20-dim basis)."""
    eta = [1] * p + [-1] * q
    f = lambda R: X(xi(R, eta))
    return bilinear_fit(f, f, p, q, conv)


def response_basis(p: int, q: int) -> list:
    """The four maps R -> *^-1 b_i(R) whose span contains X(xi R) for X with B02 response (a, b, c, d):
    *X(xi R) = a E_F(Ric) + b E_F'(Ric) + c S E_F(g) + d S E_F'(g) (`gates.response`)."""
    from gu.shiab import embed_tensor
    from gu.cliffform import scale
    eta = [1] * p + [-1] * q
    g = np.diag(eta).astype(np.int64)
    inv = lambda x: SO2.star_inv(x, eta, "pinned")
    return [lambda R: inv(embed_tensor(ricci(R, eta), 1, 0, p, q)),
            lambda R: inv(embed_tensor(ricci(R, eta), 0, 1, p, q)),
            lambda R: inv(scale(embed_tensor(g, 1, 0, p, q), GQ(int(scalar(R, eta))))),
            lambda R: inv(scale(embed_tensor(g, 0, 1, p, q), GQ(int(scalar(R, eta)))))]


def response_gram(p: int, q: int, conv: str = "pinned") -> list[list[dict]]:
    """G[i][j] = bilinear_fit(b_i, b_j). For X with response r, Q_X = sum_ij r_i r_j G[i][j] (bilinearity)."""
    bs = response_basis(p, q)
    return [[bilinear_fit(bi, bj, p, q, conv) for bj in bs] for bi in bs]
```

`experiments/B07/escape/weyl_dressing.py`:
```python
"""E2: the Weyl response of the dressed Shiab operator Shiab_eps (B02 test 5', made exact) at a 4D point.

Shiab_eps is (9.3) with Phi^i -> eps^-1 Phi^i eps (`gu.shiab.shiab_dressed`). The dressing family is the Cayley
transform h = (1 - X)(1 + X)^-1 of X = (1/2) u_I for every blade I != 0, where u_I is the u(A) generator on blade I
(G_I or i G_I by `universal.phases`). Grade-2 blades give elements of the Spin image; every other grade does not.
For each mode (CCC, CAA with Phi = F, B; CAC with Phi1 = F + F', Phi2 = B') and each eps, record:
  leak_rank   - rank of W -> *Shiab_eps(xi W) on a basis of the 10-dimensional Weyl space (undressed: 0);
  cov_defect  - number of Weyl basis inputs with Shiab_eps(c_eps xi W) != c_eps Shiab(xi W), c_eps x = eps^-1 x eps
                (B02 proofs.md identity at eps = 1, h = eps; expected 0 for every eps);
  dressed_Q   - Q of the dressed operator fitted to the invariants (`quadratic.bilinear_fit`), or None if not in span;
  residual    - dimension of {L in spin(p,q) : rho(L) Shiab_eps = Shiab_eps rho(L) on xi(algebraic curvature)}.
Every member is checked to lie in U(A) (h^t A h = A) before the survey; skipped (singular) blades are recorded.
Identity scope on the stated finite family and bases; not a search over U(A).
"""
from __future__ import annotations

import itertools

from fractions import Fraction

from flint import fmpq, fmpq_mat

from gu.adjoint import from_mono, is_in_group
from gu.clifford import dirac_pairing, gammas
from gu.cliffform import blade_to_mono

from gu.cliffform import GQ, I, plus, scale, star
from gu.curvature import decompose
from gu.shiab import cayley_blade, eta_of, generator_action, left, phi_basis, right, shiab, shiab_dressed, xi
from experiments.B07.escape import quadratic as Q
from experiments.B07.phase2 import universal as U

MODES = ("CCC", "CAA", "CAC")


def phis_for(mode: str, p: int, q: int) -> tuple[dict, dict]:
    ph = phi_basis(p, q)
    if mode == "CAC":
        return plus(ph["F"], ph["F'"]), ph["B'"]
    return ph["F"], ph["B"]


def rank(vecs: list[dict]) -> int:
    """Exact real rank of GQ-valued vectors (real and imaginary parts as separate rows)."""
    keys = sorted({k for v in vecs for k in v})
    if not keys:
        return 0
    ix = {k: i for i, k in enumerate(keys)}
    M = fmpq_mat(2 * len(keys), len(vecs))
    for j, v in enumerate(vecs):
        for k, x in v.items():
            M[ix[k], j] = fmpq(x.re.numerator, x.re.denominator)
            M[len(keys) + ix[k], j] = fmpq(x.im.numerator, x.im.denominator)
    return M.rank()


def weyl_basis(p: int, q: int) -> list:
    """xi of an independent set of Weyl tensors (denominator * W, integer), from the curvature basis."""
    eta = eta_of(p, q)
    Ws = [decompose(R, eta).weyl for R in Q.curvature_basis(p + q)]
    Ws = [W for W in Ws if W.any()]
    return [xi(Ws[i], eta) for i in Q.independent(Ws)]


def family_report(p: int, q: int, t: Fraction = Fraction(1, 2)) -> dict:
    """{"members": [(blade, grade, eps, eps_inv)], "attempted": [...], "skipped": [...]} for X = t u_blade.

    A blade is skipped (and listed) when 1 + X is singular. t must be exact."""
    eta, ph = eta_of(p, q), U.phases(p, q)
    t = Q._q(t)
    members, attempted, skipped = [], [], []
    for blade in range(1, 1 << (p + q)):
        attempted.append(blade)
        try:
            e, ei = cayley_blade(blade, GQ(t) * (I if ph[blade] else GQ(1)), eta)
        except ZeroDivisionError:
            skipped.append(blade)
            continue
        members.append((blade, blade.bit_count(), e, ei))
    return {"members": members, "attempted": attempted, "skipped": skipped}


def family(p: int, q: int) -> list[tuple[int, int, dict, dict]]:
    """The members of family_report at t = 1/2."""
    return family_report(p, q)["members"]


def as_matrix(x: dict, p: int, q: int) -> fmpq_mat:
    """The real embedded matrix of a 0-form Clifford element {(0, blade): GQ} (gu.adjoint conventions)."""
    gs = gammas(p, q)
    M = None
    for (f, c), v in x.items():
        if f:
            raise ValueError("0-form expected")
        for coeff, ipow in ((v.re, 0), (v.im, 1)):
            if coeff:
                term = from_mono(blade_to_mono(c, gs).times_i_power(ipow)) * fmpq(coeff.numerator, coeff.denominator)
                M = term if M is None else M + term
    return M


def in_group(e: dict, p: int, q: int) -> bool:
    """h^t A h = A for the Dirac pairing A (gu.adjoint.is_in_group)."""
    return is_in_group(as_matrix(e, p, q), from_mono(dirac_pairing(p, q)))


def conj(x: dict, e: dict, ei: dict, eta: list[int]) -> dict:
    return left(ei, right(x, e, eta), eta)


def survey_one(mode: str, p: int, q: int, e: dict, ei: dict, weyl: list, curv: list) -> dict:
    eta, n = eta_of(p, q), p + q
    P1, P2 = phis_for(mode, p, q)
    S = lambda x: shiab_dressed(P1, P2, x, mode, eta, e, ei)
    leak = rank([v for v in (star(S(x), eta) for x in weyl) if v])
    defect = sum(1 for x in weyl
                 if plus(S(conj(x, e, ei, eta)), scale(conj(shiab(P1, P2, x, mode, eta), e, ei, eta), -1)))
    cols = []
    for a, b in itertools.combinations(range(n), 2):
        col = {}
        for j, x in enumerate(curv):
            d = plus(generator_action(S(x), a, b, eta), scale(S(generator_action(x, a, b, eta)), -1))
            col.update({(j,) + k: v for k, v in d.items()})
        cols.append(col)
    dq = Q.bilinear_fit(lambda R: S(xi(R, eta)), lambda R: S(xi(R, eta)), p, q)
    return {"leak_rank": leak, "cov_defect": defect, "residual": len(cols) - rank(cols), "dressed_Q": dq}


def survey(p: int, q: int, modes=MODES) -> dict:
    eta = eta_of(p, q)
    weyl = weyl_basis(p, q)
    curv = [xi(R, eta) for R in Q.curvature_basis(p + q)]
    rep = family_report(p, q)
    outside = [b for b, _, e, _ in rep["members"] if not in_group(e, p, q)]
    if outside:
        raise AssertionError(f"dressings not in U(A): blades {outside}")
    out = {"signature": [p, q], "weyl_dim": rank(weyl), "modes": {},
           "family": {"t": "1/2", "attempted": len(rep["attempted"]), "accepted": len(rep["members"]),
                      "skipped": rep["skipped"]}}
    for mode in modes:
        P1, P2 = phis_for(mode, p, q)
        rows = [{"blade": blade, "grade": g, **survey_one(mode, p, q, e, ei, weyl, curv)}
                for blade, g, e, ei in rep["members"]]
        out["modes"][mode] = {"undressed_leak_rank": rank([v for v in (shiab(P1, P2, x, mode, eta) for x in weyl) if v]),
                              "rows": rows}
    return out
```
